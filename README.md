# 映画伞里互动设计 · 猫隐 CATIN

> 一支会流动的水墨伞面。手指落墨，墨随水走，猫从墨里浮出来。

在浏览器里实时生成水墨流体的圆形伞面，用于油纸伞面设计与投影素材。

单文件 HTML，**双击即可打开**，无需安装、无需联网（字体除外）。

## 在线使用

开启 GitHub Pages 后，任何设备（手机/平板/电脑）打开：

```
https://<你的用户名>.github.io/catin-umbrella/
```

## 本地使用

双击 `index.html`，或用浏览器打开。

## 功能

| 操作 | 说明 |
|---|---|
| 按住拖动 | 在伞面上落墨，水流会带着墨自然散开 |
| 底部 6 个色点 | 玄墨 / 黛青 / 靛蓝 / 朱砂 / 竹青 / 藤黄 |
| Auto Ink | 空闲时自动滴墨并推动水流（想让它一直动就开着） |
| 保存伞面 | 下载 2000×2000 PNG（含伞骨、包边、印章、题款） |
| Wash | 慢慢洗掉重来 |
| F11 | 全屏，投影时用 |

## 规格

| 项 | 值 |
|---|---|
| 输出比例 | 1:1 正方形画布，圆形伞面占 86% |
| 伞骨 | 32 根，每 11.25°，骨位末端渐隐 |
| 品牌位置 | **伞面外右上空白区**（互动产品署名位；如需印刷版可改回圆内 0.82R） |
| 品牌字体 | 「猫隐」书法体 + 「CATIN」「映画伞里互动设计」宋体 |
| 保存分辨率 | 2000 × 2000 PNG（手机端走系统分享，可直接存相册/发微信） |
| 目标印刷规格 | 直径 3.6 m 圆料 / 建议 150 DPI（≈21260 px，需离线渲染，见下） |

## 已知限制

1. **当前版本只出屏幕级分辨率**（2000 px）。3.6 米印刷需 21260 px，必须走离线高精度渲染，不能靠放大——流体浓度场本身只有 1280 分辨率，放大只会糊。
2. 流体随机生成，**同一构图不可复现**。要做订制业务（客户确认过的图必须能重现），需要加参数包 + 随机种子锁定。
3. 纯墨流是**抽象底纹**，没有题材。用于订制伞面还需叠加主体意象（如猫隐的水墨猫）与题款。
